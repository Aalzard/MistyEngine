## Open / not fixed

- **B3** (W) tilemap compound colliders without parry `FIX_INTERNAL_EDGES`: bodies can catch on
  seams. Needs a physics behaviour check; not done.
- **B6** (P) tilemap chunk cache keyed by entity bits only: two scenes drawn in turn with the same
  entity ids rebuild chunks each frame. Correctness is safe (content hash); perf only. Not done.
- **T6** (P) `render/terrain.rs` hole index lists rebuilt wholesale on any holed chunk LOD
  change. Render code (needs a golden run); not done.
- **Physics exit events for destroyed objects**: won't fix. Matches the familiar engine (no
  `OnTriggerExit`/`OnCollisionExit` when the other collider is destroyed); delivering a contact
  with a dead entity to scripts would need a placeholder object.
- **asset.read_text** (P) reads the whole file before truncating to the limit; only costs memory
  on huge files. Not done.
- **Lua `pcall` around an endless loop** (`while true do pcall(function() while true do end
  end) end`) still hangs: the deadline error is catchable. Same limit as the editor scripts.
- **ReliableOrdered `buffered`** can hold up to 32k early parts per connection (~40 MB) from a
  hostile peer: bounded, left as is.
- **SaveSystem.version** wraps at 2^32, `name_from_path` for dotfiles, `rewrite_text` case on
  Windows, Play exit and `inspector_targets`: X items, not done.
