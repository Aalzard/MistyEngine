## Open (not fixed this round)

- Script Graph Collapse To Macro copies the outer graph's variables into the macro, and a
  macro's own Graph variables are private: nodes collapsed into a macro silently stop
  reading or writing the outer variable. Needs a decision on macro variable scope (shared
  with the owner, or private as the `macros_and_subgraph_assets_inline_with_their_own_state`
  test wants).
- Script Graph subgraph inlining has a depth limit (16) but no size limit: distinct assets
  that each use the next several times inline exponentially many copies.
- Two editors on one project: no project lock (both autosave layouts, scenes and terrains;
  the second takes the MCP info file over).

- Virtual cameras: a brain with no live camera, priority ties.
