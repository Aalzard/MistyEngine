Misty Engine changelog
======================

0.2.0 - speed, trees, multiplayer and Linux (November 2026)
-----------------------------------------------------------

Now on Linux
- A Linux x64 download next to the Windows one (extract, run ./MistyEngine). The in-app
  updater picks the right package on each system.

Faster
- Grass is drawn about twice as cheaply (each grass pixel is shaded once), and is culled on
  the GPU. MeadowDemo at 1080p on Medium went from about 57 to 84 FPS, and the editor's
  Game view from about 98 to 168 FPS.
- Upscaling (Quality > Upscaling: Off / Quality / Balanced / Performance / Custom): render
  below full resolution and rebuild a sharp image. Medium at 1080p reaches 100+ FPS with it.
- No more freeze when pressing Play or opening a scene: textures load in the background and
  compiled GPU programs are cached on disk.
- The editor no longer waits for the screen refresh by default (VSync switch in the Game
  view), so the FPS you see is the real one.

The editor
- Smoother Scene camera: gliding fly, orbit and zoom, raw mouse look, zoom towards the
  cursor, and speed / acceleration / damping settings under the camera button.
- Editor scripting in Lua: your own menu items, tool windows, custom Inspectors, gizmos and
  handles from scripts in an Editor folder (see the Tools > Scatter Tool sample).
- Inspector attributes for script fields: Header, Tooltip, Space, Range, HideInInspector.

Multiplayer
- Netcode: Network Manager, Network Object and Network Transform (interpolation and
  prediction), network variables and server/client RPCs from Lua, LAN discovery.
- Multiplayer Play Mode: tick 2-4 players and press Play; extra player windows join your
  game. See the NetworkDemo sample scene.

World and art
- Trees: oak, linden and birch from editable .tree recipes, with wind, shadows, LODs and
  far impostors, and a Paint Trees tab on the Terrain. MeadowDemo has 184 of them.
- Realistic tree materials: PBR bark (relief, roughness, ambient occlusion, parallax) and
  leaves with light shining through; gnarled oak limbs and root buttresses.
- MeadowDemo now uses Misty GI (live bounce light and sky shading under the trees).
- The tree and meadow assets are free to use in your own games (CC0).

Experimental (off by default, try them in Quality settings)
- Misty GI: real-time global illumination without baking (Quality > Global Illumination,
  or the Lighting window).
- Virtual shadow maps: sharper sun shadows with cached pages (Quality > Shadows > Virtual).
- Virtual geometry: Nanite-style cluster rendering for very dense meshes (model import
  setting).

Fixes
- Creating a project with "Include sample scenes" could fail with "os error 2"; errors now
  name the file, and the release build no longer opens a console window.

0.1.0 - big test update (November 2026)
---------------------------------------

The editor
- A new look: no Windows frame, our own title bar with the project name in the middle, flat
  play buttons, Inspector components as clean cards with bold titles, no black outlines.
- Hierarchy: striped rows, parents highlighted like folders, tree lines, and real Folders you
  can colour with Alt + right-click. Right-click an object for Move To View / Align With View.
- Scene view: Gizmos menu (icon size and colour) and a Quality menu (quality level, FXAA,
  render scale, Bilinear / Nearest / Sharpen).
- New projects: two templates, Standard and PP Ready (sunset over the ocean, clouds, god rays),
  and an "Include sample scenes" checkbox. The Hub shows each project's last view.

Gameplay
- Vehicles with Wheel Colliders (suspension, tyre grip, motor, brakes, steering).
- Skinned characters from glTF with blend shapes, and animation rigging (Two Bone IK, Aim,
  Chain IK, Damped Transform).
- Timeline for cutscenes, and virtual cameras with blends, follow, orbit, framing and shake.

Content tools
- Mesh Builder: model shapes inside the editor (extrude, inset, bevel, loop cut and more).
- Splines (roads, tubes, objects along a path), Tilemaps with a Tile Palette and 2D lights.
- Shader Graph, and the Effect Graph for GPU particles (millions of them).

Lighting
- Baked global illumination (lightmapper), light probes for moving objects, occlusion culling.

Systems
- Save system and localization (string tables, language switching).
- Video Player and rich text (colours, bold/italic, icons, outlines).
- Asset groups loaded by address, and a Package Manager.
- Test Runner for Lua tests, Frame Debugger and Memory Profiler.

0.0.1 - first test version (November 2026)
------------------------------------------

The first public test version. Everything below is new.

Misty Hub and getting started
- Misty Hub: the start screen with your recent projects (with pictures), search, Open and
  "Show in Explorer".
- New projects from four templates: Empty, Standard (a platform to build on), Ocean (sea and
  sky) and Landscape (a generated world with clouds, fog and sun shafts).
- Learn: four interactive tutorials inside the editor (post-processing, god rays, terrain,
  World Builder). A step card tells you what to do and the place to click lights up.
- File > Open Misty Hub goes back to the Hub.
- Updates: Misty Engine checks for new versions and installs them with one click (the download
  is checked before anything changes, and a failed update is undone).
- New logo, window and program icons, a splash screen and an About window.

Editor
- Dockable windows: Hierarchy, Scene, Game, Inspector, Project, Console, Animation and more,
  with saved layouts.
- Scene view: fly, orbit and pan; move, rotate and scale tools; snapping; 2D mode; draw modes.
- Undo and redo for everything, with an Undo History window.
- Ctrl+K search: objects, assets, menu commands, settings and help in one box.
- Several scenes open at once (additive scenes, move objects between scenes).
- Prefabs with overrides; Presets for components and assets.
- Asset GUIDs (.meta files): renaming or moving assets keeps references working.
- A built-in Code Editor for Lua and shaders, with error marks.
- Project Settings: Player, Quality, Input, Tags and Layers, Physics, and more.

Rendering
- Physically based materials (Standard shader) and unlit shaders; textures and 3D models (glTF
  and OBJ).
- Directional, point, spot and rectangle area lights; soft shadows (PCSS) and cascaded sun
  shadows.
- Reflection probes with automatic placement; ambient occlusion and contact shadows.
- Post-processing: tonemapping, bloom, color adjustments, vignette, fog and more.
- Volumetric fog with sharp sun shafts; volumetric clouds; HDRI skies.
- Light halos and lens flares.
- Custom shaders (WGSL) and a water system: oceans, lakes and rivers with waves, foam and fog.

Worlds
- Terrain: sculpt, paint layers, Auto Paint rules, cliffs, grass and trees.
- World Builder: a whole landscape from settings: landform, erosion, mountains, ocean, biomes,
  trees and rocks.

Gameplay
- Play, Pause and Step in the editor.
- Physics (Rigidbody, colliders, joints) and a Character Controller.
- Lua scripting with Start, Update, FixedUpdate and collision events.
- Navigation meshes and agents.
- Animation clips and Animator controllers.
- Particle systems.
- Audio sources, listeners and Audio Mixers.
- Runtime UI (canvas, text, buttons and more) and the Input Manager with gamepads.

Builds
- Build Settings and File > Build: a stand-alone Windows game (your exe, icon and data).

Known limitations
- Windows only. 2D tools are unfinished. Some menu entries are placeholders.
